## 2. Design, development and production, and vulnerability handling processes

### 2(a) Design and development, including the system architecture

- System architecture: Three modules. zigbee-herdsman talks to the Zigbee adapter and offers an API to the layers above; zigbee-herdsman-converters maps each device model to the Zigbee clusters it supports; Zigbee2MQTT drives zigbee-herdsman, maps Zigbee messages to MQTT messages and keeps the system state in database.db, a JSON text file of connected devices. Web front ends (zigbee2mqtt-frontend, zigbee2mqtt-windfront) give monitoring and configuration. [source: https://github.com/Koenkk/zigbee2mqtt/blob/2.14.2/README.md, retrieved 2026-10-26]
